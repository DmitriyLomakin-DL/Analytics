# Analytics

Personal repository for learning and practicing data analytics.

The repository brings together practical work with **Python, R, SQL, databases, statistics, and data visualization**.

## Tech Stack

* **Python** — data analysis and automation
* **R** — statistical analysis and data visualization
* **SQL** — data extraction, transformation, and analysis
* **PostgreSQL** — relational database
* **DuckDB** — analytical SQL engine
* **Jupyter** — interactive data analysis
* **Git & GitHub** — version control and project management
* **VS Code** — development environment

The project is developed in **Visual Studio Code** on macOS.

Python dependencies are isolated in a local virtual environment (`.venv`), which is intentionally excluded from version control.
